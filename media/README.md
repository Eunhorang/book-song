# MP3·MP4 음원 올리는 곳

곡 번호에 맞춰 `01.mp3`, `02.mp4`, `03.mp3`처럼 올리면 배포 과정에서 자동으로 연결됩니다.

- MP3와 MP4 모두 웹사이트에서는 **영상 없이 음악만** 재생됩니다.
- 같은 번호의 MP3와 MP4가 모두 있으면 MP3를 우선합니다.
- 한 파일은 95MB보다 작게 준비합니다.
- 같은 번호의 파일을 교체하면 다음 배포부터 새 음원이 재생됩니다.
- 나중에 영상을 공개할 때만 `data/media.json`의 `video` 또는 `youtube` 항목을 명시적으로 연결합니다.

# 책이 노래가 될 때

책에서 건진 질문을 노래와 가사 해석으로 다시 만나는 이정주의 음악 아카이브입니다.

## 제공 기능

- 번호순 노래 보관함과 검색
- MP4 직접 재생
- 재생 가능한 MP4 무작위 순서 재생
- YouTube 영상 연결 및 재생
- 전체 가사와 가사별 의미 해석
- 모바일·태블릿·데스크톱 반응형 화면
- 새 곡이 늘어나도 데이터로 누적되는 구조

`랜덤 노래 재생`은 사이트 최상단의 고정 메뉴에 있어 스크롤 위치와 관계없이 사용할 수 있습니다. 버튼 오른쪽의 상태 표시에는 `재생 중 · 〈노래 제목〉`이 나타나며, 재생 대기·일시정지·재생 완료 상태도 구분됩니다. 현재 `media/NN.mp4`가 연결된 곡을 중복 없이 한 번 섞어 이어서 재생하며, 파일을 나중에 추가하면 별도 코드 수정 없이 랜덤 재생 목록에 포함됩니다.

`음악 보관함`, `가사와 의미`, `프로젝트 소개`는 긴 한 페이지의 위치로 스크롤하는 링크가 아니라 각각의 독립 화면으로 전환됩니다. 화면 전환은 페이지를 새로 불러오지 않는 방식이라 재생 중인 MP4와 랜덤 재생 상태가 그대로 유지됩니다. 주소의 `view` 값으로 각 화면을 직접 열 수 있고 브라우저 뒤로가기·앞으로가기도 지원합니다.

## MP4를 나중에 올리는 가장 쉬운 방법

1. GitHub 저장소의 `media` 폴더를 엽니다.
2. **Add file → Upload files**를 누릅니다.
3. 곡 번호와 같은 이름으로 파일을 올립니다.
   - 첫 번째 곡: `01.mp4`
   - 다섯 번째 곡: `05.mp4`
4. 변경 사항을 저장하면 배포 작업이 자동으로 시작됩니다.
5. 배포가 끝나면 웹사이트에서 해당 곡의 **보관 음원** 버튼이 나타납니다.

MP4 파일은 95MB보다 작게 준비하는 것을 권장합니다. 더 큰 영상은 YouTube에 올린 뒤 아래 방식으로 연결하는 편이 안정적입니다.

## YouTube 영상 연결

`data/media.json`에서 해당 곡의 `youtube` 값에 주소를 넣습니다.

```json
"05": {
  "mp4": "",
  "youtube": "https://www.youtube.com/watch?v=영상ID"
}
```

저장하면 웹사이트에 YouTube 재생 버튼이 자동으로 생깁니다.

## 새 노래 추가

번호가 붙은 공개 곡 노트를 준비한 뒤 다음 명령으로 노래 데이터를 갱신합니다.

```bash
python3 scripts/sync_from_obsidian.py --source-dir "곡 노트 폴더"
python3 scripts/build.py
python3 scripts/verify.py
```

웹사이트 공개 화면에는 제목, 참고 도서, 중심 질문, 가사, 의미 해석, 내레이션과 마지막 질문만 담깁니다.

## 로컬 미리보기

```bash
python3 scripts/build.py
python3 -m http.server 4173 --directory dist
```

브라우저에서 `http://127.0.0.1:4173/`을 엽니다.
